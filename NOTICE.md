## Models

- **Parakeet TDT 0.6B v2** by NVIDIA
  (https://huggingface.co/nvidia/parakeet-tdt-0.6b-v2), licensed under
  CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Setup downloads
  the ONNX conversion by istupakov
  (https://huggingface.co/istupakov/parakeet-tdt-0.6b-v2-onnx, CC BY 4.0),
  which Transcribe uses unmodified.
- **Silero VAD** (https://github.com/snakers4/silero-vad), MIT. Setup
  downloads the ONNX files from https://huggingface.co/istupakov/silero-vad-onnx
  (MIT).
- **pyannote speaker-diarization-community-1**
  (https://huggingface.co/pyannote/speaker-diarization-community-1),
  CC BY 4.0, gated: each user downloads it with their own Hugging Face
  account after accepting its conditions. Used for mixed recordings only.

## Test audio

`backend/assets/smoke.wav` is 5.4 seconds of chapter 1 of LibriVox's
recording of *Alice's Adventures in Wonderland* (Version 7) by Lewis Carroll,
read by Craig Franklin
(https://archive.org/details/alicesadventuresinwonderland_2005_librivox), which
is in the public domain.

## Build tools (not shipped)

PyInstaller builds the exe; only its bootloader, loader and run-time hooks end
up inside it, as listed above. pytest runs the tests, Playwright drives the UI
flows in `tests/ui/`, and uv compiles the lock files.
